# 项目要求配置示例

这是一个配置格式示例，展示原项目采用过的筛选口径，**不是任何学校当前正式要求的声明**。不得在未获使用者确认时自动套用。

| 配置项 | 示例值 | 来源与适用范围 |
|---|---|---|
| 终稿参考文献 | 60篇以上 | 示例项目要求 |
| 选题报告参考文献 | 30篇以上 | 示例项目要求 |
| 英文文献比例 | 不少于70% | 示例项目要求 |
| 时间范围 | 优先近三年；经典理论及方法可放宽 | 示例项目要求 |
| 国内学位论文 | C9高校博士论文 | 仅针对国内学位论文，不限制期刊作者院校 |
| 期刊来源 | 行业内重点期刊 | 按主题相关性和本校标准判断 |
| 结构范文 | 3—4篇匹配的工程管理硕士论文 | 学习结构；正式引用资格单独判断 |

实际项目请复制 `assets/project-config.md`，填写本校文件、导师意见、确认日期及冲突处理。要求不明确时保留待确认，不从本示例补齐。
