# 工作流与模板索引

只读取当前分块。步骤是定位编号，不是必须顺序完成的独立审批。所有模板中的空位应以真实材料填写，模板结构按项目调整。

## 前期准备（第01—02步）

确认要求与数据，选好3—4篇范文。

### 第1步：确认研究要求与数据条件

1. 整理选题报告模板、论文规范、导师意见及时间节点，明确提交内容。
2. 盘点研究对象能提供的台账、流程、项目记录、访谈资料及历史数据，确认覆盖范围和获取条件。
3. 判断能否开展试点、收集改进前后数据；数据不足时，先缩小研究范围或调整对象。

**产出：**研究要求表、数据清单及主要缺口。

产出模板：[step-01.md](../assets/templates/step-01.md)

### 第2步：筛选3—4篇范文

1. 从往年MEM论文清单和已有论文库初筛，先看题名、摘要与目录。
2. 比较研究对象、核心问题、方法、数据与验证方式，选出符合第一部分要求的范文。
3. 为每篇确定具体用途，例如整体结构、访谈诊断、优先级模型或效果评价，避免拼接多篇目录。

**产出：**范文对比表，记录“研究什么、怎么研究、用什么证据、值得借鉴什么”。

产出模板：[step-02.md](../assets/templates/step-02.md)

## 确定论文框架（第03—05步）

拆解范文，明确研究定位，形成粗大纲。

### 第3步：让AI拆解范文框架

1. 将全文交给AI，提取研究对象、问题、成因、方法、方案和评价指标。
2. 按章节梳理“本章回答什么、依据什么、输出什么、怎样承接下一章”，不只提取目录。
3. 对关键数据、方法和结论回原文核查，记录页码，区分原文事实与AI分析。

**产出：**每篇结构笔记，以及跨论文的框架与方法对比。

产出模板：[step-03.md](../assets/templates/step-03.md)

### 第4步：确定自己的研究定位

1. 明确对象与边界：研究哪家企业、哪个产品或项目、哪个流程及时间范围。
2. 从真实材料中提出候选问题，区分现象、问题与原因，标明已有证据和待验证内容。
3. 参考范文提出初步方案，确认方法是否适合自己的数据、组织与实施条件。

用一句话概括：针对【对象】的【问题】，采用【方法】设计【方案】，通过【数据与指标】验证。

**产出：**研究定位卡与初步问题清单。仅替换公司或对象名称不构成创新，须重新诊断并说明情境调整。

产出模板：[step-04.md](../assets/templates/step-04.md)

### 第5步：形成粗大纲与对应关系

先搭建六章骨架，再细化至二级标题；关键方法与方案可列出三级标题。

| 章节 | 需要回答的问题 |
|---|---|
| 第1章 绪论 | 为什么研究，已有研究做到哪里，本文研究什么？ |
| 第2章 理论基础 | 使用哪些理论与方法，为什么适用？ |
| 第3章 现状、问题与成因 | 问题是否存在，证据是什么，原因如何核查？ |
| 第4章 改进方案 | 如何回应问题与成因，具体怎样执行？ |
| 第5章 实施与评价 | 如何验证，结果支持什么结论？ |
| 第6章 结论与展望 | 回答了什么，贡献、局限及适用条件是什么？ |

同步建立“问题—证据—成因—方法—措施—评价指标”对应表，检查是否存在无证据的问题、无用途的理论或无法验证的方案。

**产出：**粗大纲v0.1与研究对应表；暂不能确认的内容标记待验证。

产出模板：[step-05.md](../assets/templates/step-05.md)

## 文献准备（第06—08步）

检索、核验、下载与阅读，为后续论文写作备好依据。

### 第6步：按研究问题与章节检索

1. 将粗大纲拆成背景、核心概念、问题诊断、方案方法和效果评价等主题。
2. 设置中英文关键词及同义词，让AI协助推荐候选文献与检索式，再到学术数据库检索。
3. 按文献要求筛选，为每篇标明拟用章节与论点；优先补齐关键问题和研究方法的依据。

**产出：**候选文献总表与章节映射表，避免只凑数量、不明确用途。

产出模板：[step-06.md](../assets/templates/step-06.md)

### 第7步：核验题录并下载原文

1. 在数据库、出版社或高校学位论文系统核对题名、作者、年份、来源及DOI；国内学位论文另核学校与学位。
2. 标记虚假、近似题名、重复版本和信息不全条目，核实前不进入正式引用。
3. 按学校授权方式下载全文，需要时使用所在学校提供的校外访问方式，并确认实际订购权限；保留原始PDF与稳定文献ID。

**产出：**已核验文献表与原文库，分别记录“已核验、已下载、已阅读、已引用”状态。

产出模板：[step-07.md](../assets/templates/step-07.md)

### 第8步：批量翻译与分层阅读

1. 使用可用的文档翻译工具批量翻译外文PDF（工具可自行选择，本技能不依赖特定产品），保留原文对应关系，检查漏页、漏表和识别错误。
2. 先读核心范文、研究设计和关键方法，再按章节补充阅读；边读边写，不等全部文献精读后才动笔。
3. 每篇记录研究问题、对象与样本、方法、主要结论、局限及拟用章节。关键术语、公式、数据和结论对照原文并记页码。

**产出：**译文、阅读卡与分章节阅读总结。译文用于辅助理解，不能替代原文核验。

产出模板：[step-08.md](../assets/templates/step-08.md)

## 结合文献修正（第09步）

根据文献与真实材料，修订框架、方法及评价设计。

### 第9步：修订大纲与研究设计

1. 根据文献与真实资料调整研究问题和方案，删除不适用的方法及没有用途的理论。
2. 区分文献综述与理论基础：前者比较已有研究及不足，后者解释本文采用的方法与依据。
3. 明确访谈、问卷、台账分析、回测或试点如何开展，提前确定样本、时间窗、指标公式与数据来源。
4. 检查每个问题是否有证据、每项措施是否回应问题、每个效果承诺是否能够评价。

**产出：**修订框架v0.2、研究设计、指标口径表及待补数据清单。

产出模板：[step-09.md](../assets/templates/step-09.md)

## 选题报告与答辩（第10—11步）

完成选题报告修改与答辩PPT，核对两份材料一致。

### 第10步：生成并修改选题报告

1. 将修订框架、已核验文献、真实资料、研究设计与模板一起交给AI，按模板分节生成。
2. 审核背景与意义、文献综述、研究内容、方法、技术路线、预期成果、可行性与进度安排。
3. 统一对象名称、概念、数据和引用编号；未开展的调查与试点写为研究计划，未取得的结果标记待补。
4. 根据导师意见修改，记录修改位置、内容与原因，并同步更新论文大纲。

**产出：**选题报告定稿、修改对照表与待补证据清单。

产出模板：[step-10.md](../assets/templates/step-10.md)

### 第11步：制作选题答辩PPT

1. 按“背景—真实问题—研究切入点—内容与方法—方案—验证设计—进度”组织，突出主线。
2. 将核心证据、问题与方案对应关系、技术路线图转成便于讲解的图表，减少整段文字。
3. 按实际答辩时长演练，逐页核对报告中的名称、数字与方法，准备选题依据、数据条件、方法选择和研究贡献的问答。

**产出：**答辩PPT、讲稿备注与问答提纲。

产出模板：[step-11.md](../assets/templates/step-11.md)

## 研究与写作（第12—14步）

开题后开展实施评价、正文写作和提交复核。

### 第12步：收集基线、实施方案并评价

1. 保存原始数据快照，记录来源、时间范围与清洗规则，区分原始行数、有效记录和去重对象。
2. 通过台账、访谈、制度或案例交叉核查问题及原因，不能仅凭字段缺失推断流程未执行。
3. 统一改进前后的样本、分母、时间窗和指标口径；尽早启动试点，持续保留实施记录与结果。
4. 分开记录真实试点、历史回测与模拟，说明同期人员或任务变化；没有实测证据时，不写成已取得实际改善。

**产出：**调查与数据记录、改进前基线、实施记录、评价结果及局限说明。

产出模板：[step-12.md](../assets/templates/step-12.md)

### 第13步：按证据依赖写正文

推荐顺序：**第3章现状与问题 → 第4章方案并启动试点 → 第2章及第1章综述 → 第5章评价 → 回改绪论 → 结论与摘要。**

1. 先把真实问题和改进方案写清，再补充实际使用的理论与研究现状，减少返工。
2. 方案写明规则、输入输出、流程、角色责任及执行保障；评价同时说明结果、可能解释与适用边界。
3. 每完成一章，检查与前后章节的关系，更新研究对应表和待补事项。

**产出：**正文初稿、图表与附录，以及持续更新的修改清单。

产出模板：[step-13.md](../assets/templates/step-13.md)

### 第14步：复核、答辩与归档

1. 检查问题、成因、方案、指标和结论是否对应，关键事实能否追溯至原始资料。
2. 核对正文引用与文末文献，统一名称、数据、图表及格式，检查正文与PPT的一致性。
3. 按导师与答辩意见逐项修改，复核关联章节；保留原始材料、分析过程、定稿及实际提交版本。

**产出：**论文定稿、答辩材料、修改记录与归档文件。

产出模板：[step-14.md](../assets/templates/step-14.md)

## 续作与阶段衔接

框架是暂定研究设计。文献或现场证据改变问题定义时，返回相应分块修订；不强制重做已有效完成的材料。真实基线与试点可提前准备，不能等到撰写效果评价时再补造。正文建议按证据依赖写作，不机械按章节顺序推进。
